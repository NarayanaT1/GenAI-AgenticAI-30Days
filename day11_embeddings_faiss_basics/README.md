## Overview
**Embeddings** map text to numerical vectors that capture meaning.  
**Vector databases** (e.g., FAISS) store vectors and perform **similarity search**.

This toy demo uses a **local, dependency-free cosine search** (FAISS-like) to illustrate the concepts safely offline.

## Run
```bash
python embeddings_faiss_basics.py
```
