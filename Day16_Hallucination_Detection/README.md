## Objective
Understand how to detect hallucinations in LLM outputs.

A hallucination occurs when a model generates information not grounded in the provided context.

## Example

Context:
The Eiffel Tower is located in Paris.

LLM Answer:
The Eiffel Tower is located in Paris and was built in 1600.

The year 1600 is not present in the context → possible hallucination.
