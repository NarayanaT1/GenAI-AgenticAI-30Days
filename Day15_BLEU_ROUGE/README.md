
# Day 15 – Evaluating LLM Outputs (BLEU / ROUGE)

Series: GenAI / Agentic AI – 30 Days  
Author: Srimannarayana Reddi Tadi  
Brand: CloudByteHub.ai

## Objective
Learn how to evaluate text generated by language models using common metrics.

## Metrics Covered
BLEU – Measures similarity between generated text and reference text.  
ROUGE – Measures overlap of words and phrases.

## Example
Reference: "The cat is sitting on the mat"  
Generated: "A cat sits on the mat"

These metrics help measure how close the generated output is to the expected output.

## Run Example
Install dependencies:

pip install nltk rouge

Then run:

python evaluate_bleu_rouge.py
